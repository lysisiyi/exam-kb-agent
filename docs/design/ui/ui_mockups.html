顺序表已填★★
别名顺序存储 ✕sequential list ✕＋ 添加别名 前置数组与内存 · 已掌握 ✓
定义

用一段地址连续的存储单元依次存放线性表的数据元素；逻辑相邻的元素物理位置也相邻。

公式
loc(aᵢ) = loc(a₁) + (i−1) × d 随机存取 O(1) 的依据
陷阱

插入/删除平均要移动一半元素——存取快、增删慢。

来自 网课·第2讲 14:20 的笔记（3 条）
